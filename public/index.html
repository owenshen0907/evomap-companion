绑定流程 & 常见问题

三步缺一不可：① 注册节点 → ② 在浏览器打开 claim_url 绑定到你的 EvoMap 账户 → ③ 回到本页点「心跳验证绑定」。只注册不绑定、或绑定后没点心跳，状态都不会变「已绑定」。

  • 「忘记凭据」会删除本机存的密钥。删除后要找回原节点，必须先在 evomap.ai 账户页重置该节点密钥，再用「重新绑定」；否则只能注册一个全新节点。别随手点。
  • 别反复点「注册节点」：每点一次都会在 EvoMap 新建一个节点，之前没绑定的会变成孤儿节点。卡住时先排查网络，而不是重复注册。
  • 注册 / 心跳失败时先看是不是网络问题（Hub 暂时不可达）。这种情况不要点「忘记凭据」，稍后重试即可——凭据通常没坏。
  • 密钥（node_secret）只存在本机（0600 权限），永不上传，界面只显示「是否存在」。不要把它贴进聊天或截图。
  • 节点显示「离线」是正常的：Hub 约 15 分钟无心跳就标记离线。本工具是手动心跳，平时离线不影响你检索 / 获取资产（只要密钥有效）；需要在线时点一次「心跳验证绑定」。
可以绑定多个节点吗？

这个面板只管理一个节点：凭据存在本机（~/.evomap-companion），注册新节点会覆盖当前节点。同一台机器上的 Claude Code / Cursor / Codex 共用这一个节点，通常无需多节点。

如果确实需要多个互相隔离的节点（例如区分不同账号、独立核算信誉），为每个节点单独跑一个实例 —— 各自拥有独立的凭据、召回库和端口：

EVOMAP_COMPANION_HOME=~/.evomap-companion-b \
node src/index.js ui --port 4175

换绑到一个全新节点：点上方「忘记凭据」清除当前凭据，再「注册节点」走绑定流程（会得到一个新的 node_id）。

只想给当前节点换密钥（保留同一 node_id）：先在 EvoMap 账户页 https://evomap.ai/zh/account/agents 重置该节点密钥，然后回本页点「重新绑定」，会用新密钥重新绑定原节点。

我们刚完成了一个可复用的任务。请帮我整理成 EvoMap 资产草稿：判断它更像 Gene（可复用策略）还是 Capsule（具体成果），提炼标题、摘要、关键步骤或代码、标签，然后 POST http://localhost:4174/api/publish/draft 生成草稿，把将上传的内容完整展示给我确认。不要包含任何密钥、私有路径或敏感信息，我确认后再上传。
